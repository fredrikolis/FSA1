# fsa1-cli — specification

The register of decisions the **tool** is willing to freeze. What a workbook *is* is a separate
contract, in `docs/format-spec.md`; this document is about what `fsa1-cli` owes an author who runs
it.

**Intentionally under-specified.** Anything no clause forbids is admissible. A new capability needs
no clause admitting it, only the absence of one it breaks, so read this to find what a change would
*violate*, never to find permission for it.

**Nothing reads this file mechanically.** No hook under `.githooks/`, no CI job, and no test opens
it. A clause is applied by **judgment**, at triage, before a plan exists, never by a gate. And an
invariant is never **derived from the implementation**: a spec read off the code is cement poured
over whatever the code happens to do today.

**Enforcement is not spec, and status is not spec.** The command surface itself is source-owned and
lives in `fsa1-cli --help` and `--guide`, never here: an argv table copied into a document is a copy
free to drift. What is built today belongs in `ROADMAP.md`.

## Vocabulary

- **invocation** — one execution of `fsa1-cli` against one workbook, from the arguments it is given
  to the output it completes.
- **refusal** — a statement that FSA1 will not produce a value, naming the place a reader can go to
  remove the cause.
- **fault** — anything in a workbook that a rule of the workbook forbids.
- **export** — a file FSA1 writes in a format other than a workbook tree; **import** is the reverse.

## CORE — cross-cutting

- **CORE2 · never a silent wrong answer.** Every input yields a value or a refusal naming where the fault is, and a fault in one part never denies the rest its value.

## SER — external formats

- **SER2 · an export is the same workbook.** Every workbook FSA1 exports presents the same values, formulas, and display formats when reopened — by any mainstream spreadsheet or by FSA1 itself — as the workbook it was exported from.
- **SER3 · nothing is lost in silence.** Every part of a file FSA1 imports is present in what FSA1 exports, regenerated by the reopening spreadsheet, or named in a refusal.

## CLI — the tool

- **CLI1 · the tool needs no companion.** Every rule a workbook must satisfy, and every fault in a given workbook with the location an author must edit to remove it, is obtainable from a fsa1-cli invocation alone.
- **CLI4 · the terminal shows what an export would hide.** Every figure is shown over the cells it covers in the ASCII grid — as one labelled block where its name declares the range and no other figure's cover reaches into that range, a mark per cell otherwise — and a covered cell that holds a value or formula is distinguishable from one that is empty, without exporting the workbook.
